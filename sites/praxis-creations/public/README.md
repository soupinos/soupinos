# public/

Ρίξε εδώ τη φωτογραφία του γραφείου (Κέρκυρα, home-office με οθόνη) ως:

    hero-desk.jpg   ← ιδανικά WebP/AVIF, ~1600–2000px πλάτος

Κουμπώνει αυτόματα πίσω από τη σκηνή του Hero (μέσω της CSS μεταβλητής
`--hero-photo` στο `app/globals.css`). Αν λείπει, το Hero δείχνει το
ζεστό Μεσογειακό gradient fallback — δεν «σπάει» ποτέ.
