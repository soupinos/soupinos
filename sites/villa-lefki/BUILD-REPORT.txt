4. THE FOUR SYNC TRAPS — HOW EACH IS HANDLED
--------------------------------------------------------------------------------
  1) IMAGES: every "photo" is a role="img" DIV that an FX animates via
     transform (kenburns/parallax). The SCF image is applied as a
     background-image ON THAT EXACT DIV (helpers.php px_bg_style) — never an
     <img> — so the transform target is unchanged. Alt/description stays in
     aria-label. See template-parts/hero.php, editorial.php, reviews.php.
  2) REVIEWS (no drift): template-parts/reviews.php builds ONE $payload from
     the SCF reviews repeater, renders $payload[0] into the static card AND
     emits the whole $payload as JSON into [data-fx-target="reviews-data"] for
     FX-15. Single source. FX-15 adds the curly quotes at runtime, so the JSON
     stores the raw quote and the static card adds the same curly quotes the
     source hard-coded (identical first paint).
  3) FAQ TWO-COLUMN: template-parts/faq.php auto-distributes a variable repeater
     into 2 columns (ceil(n/2) / rest). FX-14 scans [data-fx-target="card"] on
     the whole __cols wrapper, so it finds every card regardless of the split
     and single-open spans both columns.
  4) COUNTERS: template-parts/proof.php writes the real value to data-fx-to and
     keeps the visible cell as "0" (no-JS placeholder). FX-08 derives decimals
     from the value (9.8 -> 1 decimal).


5. GREEK UPPERCASE
--------------------------------------------------------------------------------
Uppercase Greek display copy is stored ALREADY uppercase, WITHOUT tonos, in the
fields (design-system hard rule; CSS text-transform is never relied on for
Greek). px_gr_upper() (inc/helpers.php) is provided for any programmatic
uppercasing: it mb_strtoupper()s and then strips the tonos it would introduce
while KEEPING the dialytika (ΑΫΛΟΣ stays). Verified in rendered DOM:
ΦΩΣ ΚΑΙ ΑΛΑΤΙ / ΛΕΥΚΙΜΜΗ · ΝΟΤΙΑ ΚΕΡΚΥΡΑ / ΒΙΛΑ ΛΕΥΚΗ -> has_tonos = false.

7. HONEST FLAGS (not defects; reproduced faithfully or noted per brief)
--------------------------------------------------------------------------------
  A) HERO KEN-BURNS TRANSIENT EXTENT
     Static layout has ZERO horizontal overflow at 360/1440. While FX-06
     ken-burns runs, its scale() on the hero media transiently exceeds the
     viewport; this is contained by the hero's `overflow: clip` and
     `body { overflow-x: hidden }` EXACTLY as in the source (body is never
     horizontally scrollable, maxBodyScrollLeft=0). It is a property of the
     frozen design, not introduced here. No change made (frozen-design rule).
  B) CONTACT FORM DELIVERY
     inc/contact-form.php is a REAL AJAX handler that wp_mail()s the enquiry to
     the site contact address, preserving the source success-text UX. Delivery
     needs a working mailer on the host; with no MTA the enquiry is logged and
     the visitor still sees success. Wire an SMTP plugin in production.
  C) FX LIBRARY URLS
     theme-fx.js defaults to the source's exact jsDelivr CDN URLs (byte-faithful).
     Exposed via the `villa_fx_lib_urls` PHP filter so a CDN-less environment can
     point them at local copies without editing the theme. (The verification
     sandbox used that filter; the shipped theme keeps the CDN default.)
  D) DECISIONS KEPT AS-IS (per brief): language switcher decorative only;
     DB-00 signature moment out of scope; classic editor forced for the front
     page (admin-UX only, front-end design untouched).
